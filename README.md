## 👋 Hey there!
Welcome to the source code of my personal portfolio. I built this from scratch to showcase my journey as a developer, the projects I've shipped, and the skills I've picked up along the way.

I wanted something more than just a static page, so I packed this with 3D interactions, smooth scrolling, and custom animations!

---

## ✨ What's Inside?

I recently added some cool new upgrades to make it pop:
- 🌌 **Floating Particles:** A custom canvas particle background that reacts to your mouse.
- 🧲 **Magnetic Links:** Social buttons that "pull" towards your cursor when you hover them.
- 🖼️ **3D Project Tilt:** Hover over any project image to see it tilt in 3D space with a subtle glare.
- ⌨️ **Typewriter Effect:** A neat blinking cursor effect right on the landing page.
- 📊 **Animated Stats:** Numbers that count up smoothly as you scroll down to my stats.
- 🎭 **3D Character:** A fully interactive 3D avatar built with React Three Fiber.

---

## 🛠️ Built With

* **Frontend:** React 18, TypeScript, Vite
* **Animations:** GSAP (ScrollTrigger, SplitText)
* **3D & Canvas:** Three.js, React Three Fiber, native HTML Canvas
* **Styling:** Vanilla CSS (no component libraries, purely custom)
* **Deployment:** Hosted on Vercel with automatic CI/CD

---

## 🚀 Run It Locally

Want to mess around with the code? Feel free!

1. **Clone it down:**
   ```bash
   git clone https://github.com/Vikaumar/PortFolio.git
   cd PortFolio
   ```

2. **Install the packages:**
   ```bash
   npm install
   ```

3. **Spin up the dev server:**
   ```bash
   npm run dev
   ```
   *Open `http://localhost:5173` to see it live.*
